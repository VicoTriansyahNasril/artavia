Kebijakan Privasi

Berlaku sejak 30 Oktober 2026.

Data yang disimpan

Artavia menyimpan data yang kamu masukkan (transaksi, rekening, kategori, anggaran, catatan, dan pengaturan) di database lokal pada perangkatmu. Data ini tidak dikirim ke server Artavia; Artavia tidak memiliki server.

Data Google yang diakses

Fitur cadangan Google Drive bersifat opsional. Jika kamu menghubungkan akun Google, Artavia meminta dua izin:

  • drive.appdata: membuat, membaca, dan menghapus file cadangan Artavia di folder data aplikasi yang tersembunyi di Google Drive milikmu.
  • drive.file: hanya untuk file yang dibuat oleh Artavia sendiri (dipakai untuk membaca cadangan versi lama).

Artavia tidak bisa melihat, membaca, atau mengubah file lain di Google Drive kamu. Alamat email akunmu hanya ditampilkan di aplikasi agar kamu tahu akun mana yang terhubung.

Cara data Google digunakan

File cadangan berisi salinan database Artavia dan dipakai hanya untuk mencadangkan dan memulihkan data kamu. Jika kamu memasang kata sandi cadangan, isi file dienkripsi (AES-256-GCM) sebelum diunggah. Artavia menyimpan paling banyak 5 cadangan terbaru dan menghapus yang lebih lama.

Data Google tidak dijual, tidak dibagikan ke pihak ketiga, tidak dipakai untuk iklan, dan tidak dipakai untuk melatih model AI. Penggunaan data dari Google API mematuhi Google API Services User Data Policy, termasuk ketentuan Limited Use.

Menghapus data

  • Data lokal terhapus jika aplikasi di-uninstall atau datanya direset dari Pengaturan.
  • Putuskan Google Drive dari halaman Cadangan di aplikasi, atau cabut aksesnya di myaccount.google.com/permissions.
  • File cadangan dapat dihapus di Google Drive (web) melalui Setelan → Kelola aplikasi → Artavia → Hapus data aplikasi tersembunyi.

Izin lain di perangkat

Notifikasi dipakai untuk pengingat harian, dan sidik jari/biometrik hanya untuk membuka kunci aplikasi. Keduanya diproses di perangkat.
