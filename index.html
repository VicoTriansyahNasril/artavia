Artavia

Artavia adalah aplikasi Android untuk mencatat keuangan pribadi: pengeluaran, pemasukan, transfer antar rekening, anggaran, transaksi berulang, dan laporan bulanan.

Data tetap di perangkatmu

Semua transaksi disimpan di HP kamu sendiri. Artavia tidak punya server, tidak memakai iklan, dan tidak memasang analitik.

Cadangan ke Google Drive (opsional)

Jika kamu menghubungkan akun Google, Artavia menyimpan file cadangan di folder data aplikasi yang tersembunyi di Google Drive milikmu sendiri. File itu bisa dikunci dengan kata sandi.

Kebijakan Privasi

Artavia adalah proyek pribadi yang dibagikan sebagai file APK.
